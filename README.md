Student Database Assignment

Description
This assignment demonstrates my understanding of basic SQL operations using MySQL Workbench. I created a student table and practised inserting and updating student records.

Tasks Completed
1. Created a `student` table with ID, fullName, and age columns.
2. Inserted three student records into the table.
3. Updated the age of the student with ID 2 to 20.
4. Retrieved all student records using SELECT.

Tools Used

- MySQL
